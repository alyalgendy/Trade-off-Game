FORMAT
  Mono WAV, 16-bit, 44100 Hz. OGG versions in /ogg for lighter builds.

WANT VARIATION?
  A spell cast a hundred times sounds like a loop when it is always the same
  file. The full Magic Spells SFX pack ships 12 genuinely different versions
  of every spell (360 sounds), plus Unity and Godot scripts that play them
  from a shuffled bag so nothing repeats back-to-back.
  https://willosuna.itch.io/magic-spells-sfx

HOW IT WAS MADE
  Procedural synthesis from original code. No recordings, no third-party
  samples, no generative AI.
